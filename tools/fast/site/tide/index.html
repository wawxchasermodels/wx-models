Data: NOAA CO-OPS tide predictions and water levels · NOAA STOFS-2D-Global guidance (public domain) · Conditional Prediction is experimental, not an official forecast

Official prediction and observed water level: NOAA CO-OPS Data API (api.tidesandcurrents.noaa.gov), datum MLLW, feet. Flood threshold: CO-OPS metadata API (NOS or NWS minor flood level converted to MLLW).

Conditional Prediction (experimental): official prediction + forecast non-tidal residual. Residual = NOAA STOFS-2D-Global sub-tidal water level (combined minus model tide: pressure and wind surge plus its sea level anomaly), smoothed over 3 h and bias-corrected to the current observed residual (the correction fades with a 12 h e-folding time). After the STOFS run ends it relaxes (24 h) to the 30-day mean observed residual, which carries slow coastal sea level anomalies such as coastally trapped Kelvin waves / El Niño. If STOFS is unavailable the current residual is persisted and relaxed to the 30-day mean. NOAA does not endorse this site.
